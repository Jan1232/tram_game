# tram_game

Прототип narrative-симулятора смены кондуктора в трамвае (Godot 4.7).

## Запуск

1. Открыть папку проекта в Godot 4.7+
2. Main scene: `res://scenes/main.tscn`

## Управление

- **WASD / стрелки** — движение
- **E** — сесть / встать / обилечить пассажира

Подробный статус прототипа см. документы `GDD_Conductor_Vertical_Slice.md` и `TECH_Architecture_Prototype.md`.
